# Travel Analytics for Solo Travelers

> **SOLOTRACK — 자가용 없이도 즐기는 교통친화여행**  
> 국민여행조사와 교통·관광 데이터를 결합해 혼행객의 교통 접근성, 관광 소비, 지역 관광 활성화 전략을 분석한 프로젝트입니다.

## Overview

본 프로젝트는 대중교통 의존도가 높은 **1인 여행객(혼행족)** 관점에서 지역별 교통 인프라 격차를 정량화하고, 교통 접근성 개선이 관광 소비에 미칠 수 있는 영향을 분석했습니다.

분석은 다음 네 단계로 구성했습니다.

1. 시군구 단위 **교통 인프라 지수** 구축
2. 국민여행조사 기반 **지역별 자가용 의존도** 산출
3. 혼행객 **관광 소비 예측 모델** 구축 및 교통 인프라 개선 시나리오 분석
4. 교통 취약 지역과 인근 교통 거점을 연결하는 **관광 루트·교통패스 제안**

## 1. Transport Infrastructure Index

교통 인프라를 다섯 영역으로 구성했습니다.

- **Supply**: 접근 가능한 교통시설 수, 정류장·철도역 밀도
- **Demand**: 대중교통 통행량, 1인당 대중교통 이용량
- **Accessibility & Convenience**: 평균 접근시간, 평균 환승횟수, 평균 환승대기시간
- **Connectivity**: 환승 이용 비율, 환승 통행량
- **Operational Efficiency**: 평균 통행거리

왜도가 큰 일부 변수는 로그 변환하고, 변수 단위 차이는 표준화로 보정했습니다.  
시군구별 대중교통 통행량을 종속변수로 회귀분석을 수행한 뒤 회귀계수를 정규화하여 지수 가중치로 활용했습니다.

기존 분석 코드에서 회귀모형 설명력은 **R² = 0.9523**으로 확인되었고, VIF를 통해 설명변수 간 다중공선성도 점검했습니다.

## 2. Private-Car Dependency

국민여행조사에서 다음 조건을 기준으로 데이터를 필터링했습니다.

- 동반자 수: 본인 포함 1명
- 여행 목적: 관광
- 여행지별 교통수단을 자가용 / 비자가용으로 구분

이후 각 지역 방문 시 **자가용 이용 비중**을 계산하여 지역별 자가용 의존도를 산출했습니다.

## 3. Solo-Traveler Spending Prediction

지역 단위로 국민여행조사 변수와 교통 인프라 지수, 자가용 의존도를 결합해 혼행객의 평균 여행 소비를 예측했습니다.

### Validation Design
- Train: 2022–2023
- Test: 2024
- Model: XGBoost Regressor
- Target: 지역별 1인당 평균 여행 지출

### Performance

| Metric | Score |
|---|---:|
| RMSE | 42,864.77 |
| MAE | 25,792.37 |
| R² | **0.7738** |

2024년 전체 혼행객 소비액 기준으로 실제값은 **33,540,392원**, 모델 예측값은 **33,674,840원**으로 집계되었습니다.

## 4. Infrastructure Improvement Scenario

교통 인프라 지수가 **하위 30%**인 지역의 지수를 최대 수준까지 높이는 가상 시나리오를 적용해 소비 변화를 다시 예측했습니다.

| Metric | Scenario Score |
|---|---:|
| RMSE | 42,314.68 |
| MAE | 25,695.40 |
| R² | **0.7839** |

시나리오 적용 후 총 소비 예측액은 **33,745,904원**으로, 실제 2024년 소비액 대비 **205,512원 증가**하는 결과가 도출되었습니다.

이 결과는 인과효과의 추정이라기보다, 교통 인프라 수준을 변화시켰을 때 기존 예측모형이 산출하는 소비 변화의 **시나리오 분석**으로 해석했습니다.

## 5. Tourism Route Design

교통 인프라 지수가 낮고 자가용 의존도가 높은 지역을 **교통 취약 지역**으로 정의했습니다.

- 행정경계 데이터를 GeoDataFrame으로 변환
- 시군구 중심좌표 계산
- 관광지 위·경도와 행정구역 매핑
- 교통 인프라 지수 및 자가용 의존도 결합
- 취약 지역 반경 50km 내 교통 인프라가 상대적으로 높은 지역을 보완 거점으로 탐색
- 관광지와 교통 거점을 연결한 시범 관광 루트 설계

최종적으로 지역 간 대중교통 연계와 관광패스를 결합해, 자가용 없이 이동하는 혼행객의 접근성을 높이는 정책 아이디어로 연결했습니다.
