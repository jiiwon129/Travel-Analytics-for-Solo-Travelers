# Data

This project uses external public datasets and competition materials. Large raw files are intentionally not committed to this repository.

Main sources used in the original analysis include:

- 2022–2024 National Travel Survey domestic-travel microdata
- public-transport stop supply and usage indicators
- public-transport transfer convenience indicators
- transport accessibility indicators
- railway station information
- regional population data
- tourism attraction data
- administrative boundary data

The notebooks keep the original analysis logic and may contain Google Colab paths that need to be replaced with local paths before execution.
